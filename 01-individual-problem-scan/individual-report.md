#### Problem Card #1 — Code tiền xử lý dữ liệu Data Science

```text
Problem 1 câu: Sinh viên Data tốn 30-60 phút tra cứu và viết thủ công các đoạn code dọn dẹp dữ liệu (cleaning, formatting) mỗi khi nhận dataset mới.

Actor: Sinh viên làm project Data.

Thời điểm / bối cảnh: Bắt đầu một project mới, vừa tải dataset thô về máy.

Current workflow 3-7 bước:
1. Load data vào notebook.
2. Quét bằng mắt các cột thiếu (NaN) hoặc sai định dạng.
3. Lên Google/Docs tra cứu lại syntax Pandas.
4. Gõ code để dọn dẹp và biến đổi từng cột.

Non-AI alternative: Dùng các file "template" code cũ đã lưu, tự copy/paste và đổi tên biến.

AI hypothesis: Đưa vài dòng sample data vào, AI sẽ tự viết script làm sạch tối ưu nhất cho bộ data đó.
```

**Vì sao (2-3 câu: workflow gì, số đo gì, impact gì):**

```text
- Workflow rất thực tế: Đọc code AI sinh ra -> Nghi ngờ -> Thoát IDE lên Google tra Docs gốc -> Chốt dùng hay bỏ.
- Số đo rõ ràng: Hiện tại mất tới 15-20 phút cho một lần cross-check, giải pháp mới kỳ vọng ép AI tự crawl web và kiểm chứng lại trong dưới 3 phút.
- Impact: Xóa bỏ sự hoài nghi khi sử dụng AI, giúp lập trình viên giữ được mạch tập trung, không bị đứt gãy luồng suy nghĩ.
```

**Câu hỏi tôi muốn nhóm challenge (1-2 câu hỏi đúng chỗ yếu):**

```text
- Nếu dùng một con AI khác (Agent) để đi kiểm tra lỗi bịa đặt của con AI ban đầu, làm sao để chắc chắn con Agent kiểm tra kia không tiếp tục bịa đặt (hallucinate) ra một kết quả giả?
- Việc gọi Agent tự crawl web mất thời gian khá lâu, liệu có nhanh hơn việc tôi tự click vào link Google Docs và ấn Ctrl+F không?
```

**AI phản biện Card (nếu có):**
- Điểm yếu AI chỉ ra: AI nhận xét rằng boundary (ranh giới) của bước kiểm duyệt cuối cùng vẫn khá lỏng lẻo. Nếu Agent đưa ra nguồn trích dẫn sai, con người vẫn phải tự đọc lại toàn bộ trang web.
- Tôi sửa gì: Đã bổ sung yêu cầu Agent bắt buộc phải trích dẫn (quote) đúng dòng tài liệu gốc kèm link trực tiếp, để con người (Human) chỉ tốn 1 phút click và nhìn đúng dòng đó, thay vì đọc cả trang.
